# Deployment

Three free services, roughly 30 minutes end to end. No credit card required at any step.

| Component | Host | Plan | Card? |
|---|---|---|---|
| Angular dashboard | Vercel | Hobby | No |
| .NET API | Render | Free (Docker) | No |
| PostgreSQL | Neon | Free | No |

**The one catch:** Render free web services sleep after 15 minutes of inactivity and take
30–60 seconds to wake. The login screen says so, so a cold link reads as a free-tier tradeoff
rather than a broken app.

---

## 1. Database — Neon

1. Sign up at [neon.tech](https://neon.tech) and create a project named `fleetops`.
2. Copy the connection string from the dashboard.
3. Convert it from the Postgres URI form to the ADO.NET form .NET expects:

   ```
   # Neon gives you:
   postgresql://user:password@ep-xxx-yyy.us-east-2.aws.neon.tech/fleetops?sslmode=require

   # .NET needs:
   Host=ep-xxx-yyy.us-east-2.aws.neon.tech;Database=fleetops;Username=user;Password=password;SSL Mode=Require;Trust Server Certificate=true
   ```

Neon's free tier is permanent (not a trial) and allows commercial use. It scales to zero, so the
first query after an idle period pays a cold start — which pairs fine with a sleeping API.

---

## 2. API — Render

1. Push this repository to GitHub.
2. At [render.com](https://render.com) → **New** → **Blueprint**, point it at your repo.
   `render.yaml` is picked up automatically.
3. Fill in the variables marked `sync: false`:

   | Variable | Value |
   |---|---|
   | `ConnectionStrings__FleetOpsDb` | the ADO.NET string from step 1 |
   | `Cors__AllowedOrigins__0` | your Vercel URL, e.g. `https://fleetops-ui.vercel.app` |
   | `Database__DemoPassword` | any password ≥ 8 characters, for the demo accounts |

   `Jwt__Key` is generated by Render and stays stable across deploys.

4. Deploy. First build takes 5–10 minutes. Check `https://<your-api>.onrender.com/health/live`.

> **Order note:** the Vercel URL is not known until step 3, and the CORS origin is needed here.
> Deploy the API first with a placeholder, then come back and correct it — CORS failures are
> silent in the browser console and easy to misdiagnose.

---

## 3. Dashboard — Vercel

1. At [vercel.com](https://vercel.com) → **Add New** → **Project**, import the repo.
2. Set **Root Directory** to `frontend`. Vercel reads `frontend/vercel.json` for the rest.
3. Before deploying, point the frontend at the API — edit
   `frontend/src/environments/environment.prod.ts`:

   ```ts
   export const environment = {
     production: true,
     apiBaseUrl: 'https://your-api.onrender.com',
   };
   ```

4. Deploy, then go back to Render and set `Cors__AllowedOrigins__0` to the Vercel URL.

### Why not host the API on Vercel too?

Vercel runs serverless JavaScript/Python functions, not long-lived .NET containers, and cannot
hold the WebSocket connection SignalR needs. The Angular build is static files, which is exactly
what Vercel is best at — hence the split.

---

## 4. Verify

```bash
curl https://your-api.onrender.com/health/live          # 200, may take 60s when cold
curl https://your-api.onrender.com/health/ready         # 200 once Neon is reachable
open https://your-ui.vercel.app                         # sign in as admin
```

Sign in with `admin` and the `Database__DemoPassword` you set. The seeder creates six vessels
and the simulator begins emitting telemetry within 20 seconds.

---

## Keeping the demo warm (optional)

A free cron pinger such as [cron-job.org](https://cron-job.org) hitting
`https://your-api.onrender.com/health/live` every 10 minutes keeps the container awake during
the day. Render's free tier allows 750 hours/month, which is not quite a full month of uptime —
schedule it for business hours rather than 24/7.

## Cost if you ever move to real AWS

For reference, and the reason this project does not:

| Service | Monthly |
|---|---|
| EKS control plane | ~$73 |
| 2 × t3.medium nodes | ~$60 |
| RDS db.t3.micro | ~$15 (free for the first 12 months) |
| ALB | ~$20 |
| S3 + Lambda + CloudWatch at demo volume | < $1 |
| **Total** | **~$170/month** |

If you do want real AWS on a budget, ECS Fargate Spot with a single task plus RDS free tier
lands nearer $10/month. Set `use_localstack = false` in `infra/terraform` and read
[ADR 0004](adr/0004-zero-cost-local-substitutes.md) first.
